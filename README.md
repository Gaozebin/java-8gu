# ✅Redis是AP的还是CP的？

`核心观点：Redis本质上是AP（可用性优先）系统`。

#### 常见误解
单机Redis是CP，集群Redis是AP。
#### 反驳理由
CAP理论适用于分布式场景。单机无“P”（分区容错），讨论AP/CP失去意义。

## 为何是AP？最终一致性模型
- 设计目标：高性能、高可扩展性、高可用性。
- 一致性模型：最终一致性（Eventual Consistency）

**核心原因**
- 修改操作异步发送至其他节点。
- 网络延迟导致同步延迟和不一致

```
     Async
Data ————>Node1,Node2

```
